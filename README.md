# study-videos-originals

Original versions of the explainer videos on the [AI Engineer Study Companion](https://kishore2494.github.io/ai-engineer-study-companion/).
When a video is remade (one scene swapped for an animation), its first version is kept here at `videos/<id>.mp4|vtt|jpg`
and the main site's player offers a **New / Original** switch. This site's front page lists every original with the
same player.

Files are added by `study-videos/tools/upload.mjs --keep-old`; do not delete them.
